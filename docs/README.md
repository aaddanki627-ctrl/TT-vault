# TrustVault
Secure doc sharing. Roles: ADMIN, OWNER, VIEWER. See API_DOCS.md, DB_SCHEMA.md, THREATS.md.

## Run locally
Backend: cd backend && npm install && npm run dev (needs MongoDB)
Frontend: cd frontend && npm install && npm run dev

## Deploy
Frontend -> Vercel (root: frontend). Backend -> Render (root: backend). DB -> MongoDB Atlas.
